## What this repository contains
Only original source code (recompiler, analyzer, runtime, IOP emulation) under the GPLv3. It does **not** contain, and must never contain:

- Game executables (ELF), disc images, or any file extracted from a disc
- Game assets (textures, models, audio, video, scripts)
- Console BIOS or firmware dumps
- Code generated by running the recompiler on a game
- Sony SDK headers, libraries, documentation or other proprietary material
- Official logos, artwork or screenshots of commercial games

## Rules for users
- You must legally own the game and extract the files from your own disc.
- Do not ask for, share, or link to game files, BIOS files or pirated copies.
- Do not redistribute output generated from a game.

## Rules for contributors
- Contribute only code you wrote yourself or that is licensed compatibly with GPLv3.
- Do not paste or derive code from leaked or proprietary sources (Sony SDK, leaked source, NDA material).
- Do not add features that circumvent encryption, copy protection or DRM.
- Do not add commercial features, payments or donation links tied to the project.

## Naming and branding
Do not present the project as official. Do not use Sony or game logos or key art. Use wording such as "unofficial" and "requires your own copy of the game".

## Community moderation
Requests for ISOs, ROMs or BIOS files, and links to them, are removed on sight (GitHub issues, discussions and Discord). Repeat offenders are banned.

## Takedown requests
If a rights holder believes something here infringes their rights, please open an issue or contact the maintainer. Good-faith requests will be handled promptly.
